# SONIC

**SONIC** is a self-hosted personal AI assistant. Its primary focus is a private, extensible assistant that understands conversations, remembers only owner-approved facts, and connects to authorized devices and tools. It is not an architecture-only tool.

This repository is being bootstrapped with a standalone Python/FastAPI backend, OpenAI-powered brain, owner-authenticated chat UI, explicit memory, and a restricted Windows companion for TRADEVICEPC.

> Preview safety: only read-only system snapshots are permitted on connected PCs in V0.1. No shell execution, process control, unattended software operation, trading, filesystem mutation, or general computer control.

See the docs and source in the upcoming feature branch for setup and tests.
